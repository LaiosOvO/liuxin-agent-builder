<im_mock_fixture_design>
**MockIMProvider 在测试环境替换真实 provider 的机制**：

1. 后端测试启动时（conftest.py fixture）：
   ```python
   @pytest.fixture(autouse=True, scope="session")
   def mock_im_providers():
       from app.agent_builder.notification.providers.base import (
           clear_providers, register_provider, KNOWN_PROVIDERS,
       )
       from app.agent_builder.notification.providers.mock import MockIMProvider
       clear_providers()
       mocks: dict[str, MockIMProvider] = {}
       for name in KNOWN_PROVIDERS:
           m = MockIMProvider(name=name)
           register_provider(m)
           mocks[name] = m
       yield mocks
       clear_providers()
   ```

2. E2E spec 内通过 backend test-only endpoint 拉取 mock 调用记录：
   ```python
   # backend/app/agent_builder/api/test_helpers.py（仅 ENABLE_TEST_API=1 时挂载）
   @router.get("/test/im_mock_calls")
   async def get_mock_calls(provider: str) -> list[dict]:
       from app.agent_builder.notification.providers.base import get_provider
       p = get_provider(provider)
       return [{"method": c.method, "recipient": c.recipient, "payload": c.payload}
               for c in p.calls]
   ```

3. Spec 内：
   ```typescript
   const calls = await api.get(`/api/test/im_mock_calls?provider=feishu`);
   expect(calls).toHaveLength(1);
   expect(calls[0].method).toBe('send_hitl_card');
   expect(calls[0].payload.deeplinks).toHaveLength(3);
   ```
</im_mock_fixture_design>

```typescript
// e2e/helpers/safe-links-uas.ts
export const OUTLOOK_SAFE_LINKS_UA = 'Mozilla/5.0 (compatible; MSIE 11.0; Microsoft Office Outlook 16.0)';
export const MICROSOFT_DEFENDER_UA = 'Mozilla/5.0 SafeLinksScanner/1.0';

// 每 chain spec 末尾：
test('Safe Links bot GET does not consume jti', async ({ page, request }) => {
  await page.setExtraHTTPHeaders({'User-Agent': OUTLOOK_SAFE_LINKS_UA});
  const resp = await page.goto(deeplinkUrl);
  expect(resp.status()).toBe(200);

  // 断言 jti 仍未消费
  const tokens = await request.get(`/api/test/hitl_tokens?jti=${jti}`).then(r => r.json());
  expect(tokens.used_at).toBeNull();
});
```
