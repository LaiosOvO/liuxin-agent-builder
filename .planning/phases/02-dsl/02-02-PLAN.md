```json
  },
  "nodes": [

      "config": {}
    },
    {
      "id": "llm_review",
      "type": "llm",
      "position": {"x": 300, "y": 200},
      "config": {
        "model": "openai/gpt-4o",
        "system_prompt": "你是 HR 助理",
        "user_prompt": "请审核 {{ start.employee_id }}",
        "temperature": 0.7,
        "timeout_sec": 30,
        "retry_count": 3,
        "backoff_base_sec": 1
      }
    },
    {
      "id": "branch",
      "type": "if_else",
      "position": {"x": 500, "y": 200},
      "config": {
        "conditions": [
          {"expr": "{{ llm_review.message | length > 100 }}", "target_node_id": "end_ok", "label": "long"}
        ],
        "default_target": "end_no"
      }
    },
    {"id": "end_ok", "type": "end", "position": {"x": 700, "y": 100}, "config": {}},
    {"id": "end_no", "type": "end", "position": {"x": 700, "y": 300}, "config": {}}
  ],
  "edges": [
    {"id": "e1", "source": "start", "target": "llm_review"},
    {"id": "e2", "source": "llm_review", "target": "branch"}
  ]
}
```

**注意**：
- if_else 节点不显式声明 edges（它的下游通过 config.conditions[].target_node_id + default_target 隐式指定，DSLCompiler 加 `add_conditional_edges`）
- 其他节点（start/end/llm/tool）的下游通过 edges[] 表达
- node_id 命名规则：`^[a-z][a-z0-9_]*$` 且全 DSL 唯一
</dsl_format>

<validation_categories>
**Category 1: DAG 结构错（structural）**
- E_CYCLE: 节点连成环
- E_UNREACHABLE_END: 从 start 节点 DFS 无法到达任一 end 节点
- E_ORPHAN_NODE: 节点既无入边也无出边（除 start）
- E_DANGLING_EDGE: edge.source 或 edge.target 指向不存在的 node_id
- E_DUPLICATE_NODE_ID: nodes[] 中出现重复 id
- E_START_HAS_INBOUND: start 节点有入边
- E_END_HAS_OUTBOUND: end 节点有出边
- E_NO_START: DSL 中无 start 节点
- E_NO_END: DSL 中无 end 节点
- E_MULTIPLE_START: DSL 中超过一个 start 节点

**Category 2: 变量引用悬空（variables）**
- E_UNDEFINED_VAR: Jinja2 模板引用 `{{ x.y }}`，x 不在符号表中（节点 id + state_schema 字段名）
- E_UNDEFINED_FIELD: x 在符号表，但 y 不是 x 的输出字段（节点输出字段需在 node_schemas 中声明）

**Category 3: 节点配置类型错（config）**
- E_INVALID_CONFIG: config 不符合该 node type 的 JSON Schema（jsonschema.exceptions.ValidationError）
- E_INVALID_NODE_ID: node id 不匹配 `^[a-z][a-z0-9_]*$`
- E_INVALID_STATE_TYPE: state_schema 字段类型不在 PY_TYPE_MAP

**Category 4: 特殊**
- E_IF_ELSE_NO_DEFAULT: if_else 节点 config 缺 default_target
- E_IF_ELSE_BAD_TARGET: if_else.conditions[].target_node_id 或 default_target 不在 nodes[]
- E_NODE_ID_RESERVED: node id 命中保留字（state / event / __ptr__ 等）

每个 error 含：severity / code / message（中文）/ node_id（如有）/ edge_id（如有）/ field_path（如 `config.user_prompt`）
</validation_categories>

**SandboxedEnvironment 配置**：
```python
from jinja2 import sandbox
from jinja2.runtime import Context

def build_jinja_env() -> sandbox.SandboxedEnvironment:
    env = sandbox.SandboxedEnvironment(
        loader=None,
        autoescape=False,
        undefined=jinja2.StrictUndefined,  # 引用未定义抛错（验证时拦截）
    )
    # 清空内置 filter，加白名单
    safe_filters = {
        "tojson": json.dumps,
        "default": lambda v, d: d if v is None else v,
        "lower": str.lower,
        "upper": str.upper,
        "length": len,
        "truncate": lambda s, n=80: s[:n] + ("..." if len(s) > n else ""),
    }
    env.filters = safe_filters
    env.globals = {}  # 不暴露任何全局函数
    return env

def collect_referenced_variables(template_str: str, env: sandbox.SandboxedEnvironment) -> set[str]:
    """用 jinja2.meta.find_undeclared_variables 提取所有 {{ x.y.z }} 的顶层 'x'"""
    ast = env.parse(template_str)
    return jinja2.meta.find_undeclared_variables(ast)
```
