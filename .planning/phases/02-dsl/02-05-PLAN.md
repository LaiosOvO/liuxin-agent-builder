<init_chat_model_usage>
**LangChain 0.3+ init_chat_model**：

```python
from langchain.chat_models import init_chat_model

# 标准用法
chat = init_chat_model(
    "zhipuai:glm-4.6",
    temperature=0.7,
    max_tokens=2048,
    timeout=30,
)

# 节点配置覆盖 api_base / api_key（自部署网关 / Ollama）
chat = init_chat_model(
    "openai:gpt-4o-mini",
    api_base="http://ollama.local:11434/v1",
    api_key="ollama-dummy",
)

# 异步调用（与 LangGraph 节点 async execute 对齐）
response = await chat.ainvoke(messages)
# response: AIMessage(content="...", usage_metadata={...}, response_metadata={...})
```

**为何 init_chat_model 而非 ChatOpenAI / ChatAnthropic 直接 import**：
- 字符串配置可序列化进 DSL（用户 UI 选 provider/model → 转字符串）
- 加新 provider 仅改 DSL 不改后端代码
- LangChain 官方推荐路径，与 LangGraph 1.x 集成不打折
</init_chat_model_usage>

    1. workflow/nodes/llm.py：
       ```python
       class LLMNodeExecutor(BaseNodeExecutor):
           type = "llm"
           OUTPUT_FIELDS = ["content", "role", "usage_metadata", "model", "response_metadata"]

           async def execute(self, state, config) -> dict:
               messages = self._render_messages(state, config)
               ai_msg = await call_llm(
                   model_str=config["model"],
                   messages=messages,
                   temperature=config.get("temperature", 0.7),
                   max_tokens=config.get("max_tokens"),
                   api_base=config.get("api_base"),
                   api_key=config.get("api_key"),
                   timeout=config.get("timeout_sec", 30),
                   retry_count=config.get("retry_count", 3),
               )
               return {
                   "content": ai_msg.content,
                   "role": "assistant",
                   "usage_metadata": ai_msg.usage_metadata,
                   "model": ai_msg.response_metadata.get("model_name", config["model"]),
                   "response_metadata": ai_msg.response_metadata,
               }

           def _render_messages(self, state, config) -> list[dict]:
               if "raw_prompt" in config:
                   raw = render_jinja(config["raw_prompt"], state)
                   return json.loads(raw)
               messages = []
               if sys_p := config.get("system_prompt"):
                   messages.append({"role": "system", "content": render_jinja(sys_p, state)})
               for ex in (config.get("assistant_examples") or []):
                   messages.append({"role": "user", "content": render_jinja(ex["user"], state)})
                   messages.append({"role": "assistant", "content": render_jinja(ex["assistant"], state)})
               messages.append({"role": "user", "content": render_jinja(config["user_prompt"], state)})
               return messages
       ```
