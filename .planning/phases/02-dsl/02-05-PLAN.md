<litellm_usage>
**litellm 1.63 异步调用**：
```python
import litellm

response = await litellm.acompletion(
    model="openai/gpt-4o",  # 或 "anthropic/claude-sonnet-4-5", "zhipu/glm-4.6"
    messages=[
        {"role": "system", "content": "你是 HR 助理"},
        {"role": "user", "content": "审核员工 EMP-001 的离职"},
    ],
    temperature=0.7,
    max_tokens=2000,
)

response.choices[0].message.content  # str
response.choices[0].message.role     # 'assistant'
response.usage.prompt_tokens         # int
response.usage.completion_tokens     # int
response.model                       # 实际使用的 model name
```

**Provider API key 从 env 自动读**：
- OpenAI: `OPENAI_API_KEY`
- Anthropic: `ANTHROPIC_API_KEY`
- DeepSeek: `DEEPSEEK_API_KEY`
- Zhipu: `ZHIPUAI_API_KEY`
- Qwen: `DASHSCOPE_API_KEY`
- Azure OpenAI: `AZURE_API_KEY` + `AZURE_API_BASE` + `AZURE_API_VERSION`

litellm 自动按 model prefix 路由到对应 provider 并使用对应 env key（[Provider 文档](https://docs.litellm.ai/docs/providers)）。

**错误类型**：
- `litellm.AuthenticationError`：API key 错（不可重试）
- `litellm.RateLimitError`：限流（可重试，指数退避）
- `litellm.APIError`：服务端 500（可重试）
- `litellm.Timeout`：超时（可重试）
- `litellm.BadRequestError`：参数错（不可重试）
- `litellm.ContextWindowExceededError`：超长（不可重试，应在节点内截断）

**为何不用 LangChain ChatLiteLLM**：
- 直接 litellm.acompletion 少一层封装；messages 组装更直接
- ChatLiteLLM 是同步 + async 双形态包装，对 Jinja 模板渲染后的纯 dict messages 更繁琐
- 两者底层完全一样，效果等价；选 litellm 直接调用是项目决策（CONTEXT.md 锁定）

<llm_node_implementation>
```python
# backend/app/agent_builder/workflow/llm_client.py
import litellm
from litellm import AuthenticationError, RateLimitError, APIError, Timeout, BadRequestError, ContextWindowExceededError
from typing import TypedDict, NotRequired

RETRYABLE_LLM_ERRORS = (RateLimitError, APIError, Timeout)

class LLMResult(TypedDict):
    message: str
    role: str
    usage: dict
    model: str

async def call_llm(
    *, model: str, messages: list[dict], temperature: float = 0.7, max_tokens: int | None = None,
) -> LLMResult:
    response = await litellm.acompletion(
        model=model,
        messages=messages,
        temperature=temperature,
        max_tokens=max_tokens,
    )
    return {
        "message": response.choices[0].message.content,
        "role": response.choices[0].message.role,
        "usage": dict(response.usage) if response.usage else {},
        "model": response.model or model,
    }


# backend/app/agent_builder/workflow/nodes/llm.py
from app.agent_builder.workflow.nodes.base import BaseNodeExecutor, NodeExecutionError
from app.agent_builder.workflow.llm_client import call_llm, RETRYABLE_LLM_ERRORS

class LLMNodeExecutor(BaseNodeExecutor):
    def _default_retry_count(self) -> int: return 3
    def _default_timeout(self) -> int: return 60
    def _retryable_exceptions(self): return RETRYABLE_LLM_ERRORS
    
    async def execute(self, config: dict, state: dict) -> dict:
        messages = self._build_messages(config)
        return await call_llm(
            model=config["model"],
            messages=messages,
            temperature=config.get("temperature", 0.7),
            max_tokens=config.get("max_tokens"),
        )
    
    def _build_messages(self, config: dict) -> list[dict]:
        """从 config 组装 messages，已经过 Jinja 渲染。"""
        # raw_prompt 优先
        if config.get("raw_prompt"):
            return config["raw_prompt"]
        # 三段 prompt
        msgs: list[dict] = []
        if config.get("system_prompt"):
            msgs.append({"role": "system", "content": config["system_prompt"]})
        for example in (config.get("assistant_examples") or []):
            # example 形如 {role: 'user'|'assistant', content: '...'}
            msgs.append(example)
        msgs.append({"role": "user", "content": config["user_prompt"]})
        return msgs
```
