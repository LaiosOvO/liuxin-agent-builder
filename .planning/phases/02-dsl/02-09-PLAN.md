<frontend_validator_design>
**为何前端独立 TS 实现而非每次调用后端 /validate**：
- 体验：300ms debounce 内本地校验比远程调用快（< 50ms vs 200ms+ 网络）
- 离线：用户可在断网时编辑
- 一致：前端边界检查防止用户保存非法 DSL，少打无效后端请求
- 后端权威：发布前调 /validate 做最终复检（仍是真理源）

**TS Validator 与 Python 严格对齐**：
- 同样 4 类错误码（E_CYCLE / E_UNDEFINED_VAR / E_INVALID_CONFIG / E_IF_ELSE_NO_DEFAULT 等）
- 同样消息（中文）
- 同样的 field_path 格式

**Jinja parser 简化**：仅做模板字符串扫描提取变量引用，不真做求值（前端不需要）：
```typescript
// 用正则匹配 {{ x.y.z }}，不引入 nunjucks（~300KB）
const JINJA_VAR_RE = /\{\{\s*([a-zA-Z_][a-zA-Z0-9_]*(?:\.[a-zA-Z_][a-zA-Z0-9_]*)*)\s*(?:\|[^}]+)?\}\}/g;

export function collectVariables(template: string): string[] {
  const vars: string[] = [];
  let m;
  while ((m = JINJA_VAR_RE.exec(template)) !== null) {
    vars.push(m[1]);  // 形如 "start.employee_id"
  }
  return vars;
}
```

**dsl-validator.ts**：主入口
```typescript
import { validateStructure } from "./structure";
import { validateVariables } from "./variables";
import { validateConfigs } from "./configs";

export interface ValidationError {
  severity: "error" | "warning";
  code: string;
  message: string;
  node_id?: string;
  edge_id?: string;
  field_path?: string;
}

export function validateDSL(dsl: DSL): ValidationError[] {
  // 顶层 JSON Schema 校验（用 ajv）
  const schemaErrors = validateSchema(dsl);
  if (schemaErrors.some(e => e.severity === "error")) return schemaErrors;
  
  return [
    ...validateStructure(dsl),
    ...validateConfigs(dsl),
    ...validateVariables(dsl),
  ];
}
```

**use-debounced-validator.ts**：
```typescript
"use client";
import { useEffect } from "react";
import { useCanvasStore } from "@/lib/stores/canvas-store";
import { useValidatorStore } from "@/lib/stores/validator-store";
import { validateDSL } from "@/lib/validator/dsl-validator";

export function useDebouncedValidator(delay = 300) {
  const { nodes, edges, workflowName, stateSchema } = useCanvasStore();
  const setResults = useValidatorStore(s => s.setResults);
  
  useEffect(() => {
    const t = setTimeout(() => {
      try {
        const dsl = useCanvasStore.getState().exportDSL();
        const errors = validateDSL(dsl);
        setResults(errors);
      } catch (e) {
        setResults([{ severity: "error", code: "E_RUNTIME", message: String(e) }]);
      }
    }, delay);
    return () => clearTimeout(t);
  }, [nodes, edges, workflowName, stateSchema, delay, setResults]);
}
```

**error-popover.tsx**：
```tsx
export function ErrorPopover({ errors }) {
  return (
    <div className="space-y-2">
      {errors.map((e, i) => (
        <div key={i} className="flex items-start gap-2 text-sm">
          <Icon severity={e.severity} />
          <div>
            <div className="font-medium">{e.message}</div>
            {e.field_path && <div className="text-xs text-gray-500">字段：{e.field_path}</div>}
            <div className="text-xs text-blue-600 mt-1">{getFixSuggestion(e.code)}</div>
          </div>
        </div>
      ))}
    </div>
  );
}

function getFixSuggestion(code: string): string {
  return {
    E_UNDEFINED_VAR: "检查引用的节点 ID 拼写，确保该节点在当前节点之前",
    E_INVALID_CONFIG: "查看配置面板必填字段",
    E_CYCLE: "删除导致成环的边",
    E_IF_ELSE_NO_DEFAULT: "在 if_else 配置中添加 default_target",
    // ... 全部错误码的修复建议
  }[code] ?? "请联系管理员";
}
```

}
