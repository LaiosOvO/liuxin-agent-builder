<scoped_query_spec>
```python
# backend/app/db/scoped_query.py
from contextvars import ContextVar
from sqlalchemy import select as sa_select
current_workspace_ctx: ContextVar[UUID | None] = ContextVar('current_workspace', default=None)

class WorkspaceScopedQuery:
    """业务表 select() 统一入口，自动注入 workspace_id 过滤。

    例外：workspaces / users / roles 这三张表跨 workspace 可见（super_admin 跨 ws 查询时绕过），
    业务表（invites / audit_logs / 后续 phase 的 workflows / instances 等）必须走本类。
    """
    @staticmethod
    def select(model):
        ws_id = current_workspace_ctx.get()
        if ws_id is None:
            raise RuntimeError("WorkspaceScopedQuery requires current_workspace_ctx set")
        return sa_select(model).where(model.workspace_id == ws_id)
```
</scoped_query_spec>

<discard_all_hook_spec>
```python
# backend/app/db/checkout_hook.py
from sqlalchemy import event
def register_discard_all_hook(engine):
    @event.listens_for(engine.sync_engine, "checkout")
    def discard_all(dbapi_conn, conn_record, conn_proxy):
        cur = dbapi_conn.cursor()
        cur.execute("DISCARD ALL")
        cur.close()
```
作用：每次从 pool 借出连接前清空 session 级变量、temp tables、prepared statements，
防 Pitfall 6（PgBouncer session mode 残留导致跨 workspace 数据泄露）。
</discard_all_hook_spec>
