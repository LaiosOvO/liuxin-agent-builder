<jwt_token_types>
本 plan 涉及 3 类 JWT（全部 HS256，密钥 settings.JWT_SECRET）：
1. **Session token**（登录后 cookie）—— claims: sub=user_id, ws=current_workspace_id, exp=24h sliding, iat
2. **Email verification token** —— claims: sub=user_id, jti=uuid, exp=24h, purpose='email_verification'
3. **Invite token** —— claims: jti=uuid, workspace_id, email, target_role, exp=24h, purpose='invite'

**jti 一次性消费规则**（适用 verification / invite，Session 不消费）：
- DB 表 email_verifications 与 invites 都有 jti UNIQUE + used_at NULL→timestamp 一次性更新
- 用 `UPDATE ... SET used_at=NOW() WHERE jti=:jti AND used_at IS NULL RETURNING *`；零行说明已用过 → 拒绝
- **GET 验证页面不消费**（与 PITFALLS Pitfall 3 一致；只在 POST 落地时消费）
</jwt_token_types>
