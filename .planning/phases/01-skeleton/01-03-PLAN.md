```nginx
# /etc/nginx/conf.d/public.conf — 公网入口（开发环境用 8080 本地映射，生产用 80）
server {
    listen 80 default_server;
    server_name _;
    # 仅放行 3 条路径
    location ^~ /hitl/page/   { proxy_pass http://api:8000; <common_proxy_headers> }
    location ^~ /hitl/action/ { proxy_pass http://api:8000; <common_proxy_headers> }
    location ^~ /api/im/webhook/ { proxy_pass http://api:8000; <common_proxy_headers> }
    location / { return 403; }
}

# /etc/nginx/conf.d/internal.conf — 内网管理端（仅 docker-compose 内网或 VPN）
server {
    listen 8080;
    server_name _;
    location / { proxy_pass http://web:3000; <common_proxy_headers> }
    location /api/ { proxy_pass http://api:8000; <common_proxy_headers> }
    location /ws { proxy_pass http://api:8000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
}
```

`<common_proxy_headers>` 块：
```
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_read_timeout 60s;
proxy_connect_timeout 5s;
```

<startup_check_spec>
```python
# backend/app/core/startup_checks.py
import os, sys, logging
log = logging.getLogger(__name__)
REQUIRED_SECRETS = ["HMAC_SECRET", "JWT_SECRET"]
REQUIRED_ENV = ["POSTGRES_DSN", "REDIS_URL", "PUBLIC_BASE_URL", "WEB_ORIGIN"]
MIN_SECRET_BYTES = 32

def run_startup_checks() -> None:
    errors: list[str] = []
    for name in REQUIRED_SECRETS:
        val = os.environ.get(name, "")
        if len(val.encode("utf-8")) < MIN_SECRET_BYTES:
            errors.append(f"{name} 长度不足（实际 {len(val.encode('utf-8'))} 字节，要求 ≥ {MIN_SECRET_BYTES}）")
    for name in REQUIRED_ENV:
        if not os.environ.get(name):
            errors.append(f"必需环境变量 {name} 未配置")
    if errors:
        log.error("Startup checks failed:\n  - %s", "\n  - ".join(errors))
        sys.exit(1)
    log.info("Startup checks passed: %d secrets, %d env vars OK", len(REQUIRED_SECRETS), len(REQUIRED_ENV))
```
**在 FastAPI app 顶层导入时立即调用** `run_startup_checks()`（不放 startup event，因为 startup event 触发太晚 — uvicorn 已 bind port）。
</startup_check_spec>
