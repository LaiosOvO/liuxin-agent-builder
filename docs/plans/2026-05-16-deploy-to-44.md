## agent-builder 资源（已创建）

| 资源 | 内容 |
| ---- | ---- |
| 数据库 | `agent_builder`（owner: `agent_builder`） |
| DB 用户 | `agent_builder`（独立强密码，与 mmuser 隔离） |
| 扩展 | `pgcrypto`（提供 `gen_random_uuid()`）、`pg_trgm`（模糊查询） |
| 桥接容器 | `agent-builder-pg-bridge`（alpine:3 + socat）持久化 `--restart unless-stopped`，把 `mattermost-docker-postgres-1:5432` 桥到 `.44 host:5432` |

## 连接拓扑

```
本 Mac (localhost:15432)
    │ SSH tunnel (-L 15432:localhost:5432)
    ▼
.44 host:5432
    │ docker port forward
    ▼
agent-builder-pg-bridge:5432
    │ socat tcp-listen:5432 → tcp-connect
    ▼
mattermost-docker-postgres-1:5432 (docker net mattermost-docker_default)
    │
    ▼
agent_builder DB（PostgreSQL 18.4）
```

## 一键起隧道

```bash
# 首次：把 SSH 密码写入 .ssh_pass（不入仓）
echo '<your ssh password>' > .ssh_pass && chmod 600 .ssh_pass

# 起隧道
scripts/db_tunnel.sh up

# 查状态
scripts/db_tunnel.sh status

# 直接进 psql
scripts/db_tunnel.sh psql

# 关闭
scripts/db_tunnel.sh down
```

## .env 关键变量

```
DATABASE_URL=postgresql+asyncpg://agent_builder:<pass>@localhost:15432/agent_builder
POSTGRES_DSN=postgresql+asyncpg://agent_builder:<pass>@localhost:15432/agent_builder
POSTGRES_CHECKPOINT_DSN=postgresql://agent_builder:<pass>@localhost:15432/agent_builder
```

> `<pass>` 在 `.env` 中是明文随机 28 字符；`.env` 在 `.gitignore`，**永不入仓**。

## 风险与待办

| 风险 | 缓解 |
| ---- | ---- |
| SSH 密码弱（5 字符字典词） | **TODO 优先级 HIGH**：配 SSH key + 改服务器密码到 ≥ 20 字符随机 |
| mmuser 密码在容器 env 明文 | mmuser 是 Mattermost 内部用，与 agent_builder 用户隔离；不暴露到 agent-builder 代码 |
| agent_builder DB 与 Mattermost 数据共享一个 postgres 进程 | DB 级隔离已足够；若 Mattermost 重启需确认 bridge 容器在 mattermost-docker_default 网络 |
| socat 桥接 0.0.0.0:5432 暴露 host 端口 | 当前 host:5432 实际只在 LAN 可达（Windows Defender 默认）；正式部署前用 `pg_hba.conf` 限 host based + 防火墙限源 IP |
| 隧道断流 | `ServerAliveInterval=30` 已配；脚本支持 `up` 自动检测重启 |

## 后续阶段建议

- Phase 2 起：Alembic 通过隧道做 migration；E2E 在 CI 中用 docker-compose 起本地独立 postgres 测试，不依赖 .44
- Phase 7 部署：把 agent-builder 整套 docker-compose 部署到 .44 上，agent-builder 直接进 mattermost-docker_default 网络，按容器名访问 postgres（不再需要桥接 + 隧道）
